# Archived pages

Earlier front-ends for the optimizer engine, kept for reference. Not part of the prototype and not maintained.

- `cipro_model_explorer.html`: the original interactive explorer, replaced on 2026-11-16 by the Advisor and Twin. Still synced by `scripts/build_coil_table.py`.
- `optimizer_app.html` + `flow.js`: one-question-per-screen form of the optimizer.
- `autopilot.html` + `autopilot.js`: operator "autopilot" concept. Parked because a live control loop claims more than the data supports.

- `advisor.html` and `twin/`: the Settings Advisor and Batch Reactor Twin prototypes (built 2026-11-15). Replaced as the app by Ritik's `../removed-is-not-safe.html` on 2026-11-16. Their JS tests still run (`tests/test_optimizer.py`, `test_twin.py`, `test_protocol.py`).

The app is `../removed-is-not-safe.html`.
