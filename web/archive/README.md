- `cipro_model_explorer.html`: the original interactive explorer, replaced on 2026-11-16 by the Advisor and Twin. Still synced by `scripts/build_coil_table.py`.
- `optimizer_app.html` + `flow.js`: one-question-per-screen form of the optimizer.
- `autopilot.html` + `autopilot.js`: operator "autopilot" concept. Parked because a live control loop claims more than the data supports.

The prototype pages are `../optimizer.html` and `../twin/twin.html`.
