  1. Open the Research-Synopsys project in claude.ai and edit its instructions.

Before answering anything about this project, read claude/project-state.md (the shared status doc) and treat it as newer than every other doc. Before you finish a chat in which something was decided, built, measured or found, add a dated line to its "Decisions and results since the last sync" section with a link to this chat, and update "Open items" if one was done. If what you learn contradicts a project doc, add it under "Conflicts to resolve" instead of guessing.
