One run, start to finish

  1. Wrap the beaker in foil. Add 500 mL of pH 7.5 buffered water with 1 mg/L cipro and the stir bar. Start stirring, then write down the temperature.
  2. Set out 5 labeled vials (0, 7.5, 15, 22.5, 30 min), each already holding its quench.
  3. Take the 0 min sample before any chlorine goes in.
  4. Add the chlorine dose through the lid and start the timer that same second.
  5. At each time, pull the sample by syringe, squirt it into its vial, cap it and invert it twice.
  6. Run a blank beaker (chlorine, no cipro) and check its chlorine with DPD at the same times, to see how fast chlorine fades on its own.
  7. Filter the HPLC portion and keep every sample cold and dark until it's measured.

Safety

  • Never mix bleach stock and ammonium chloride stock directly. That can release toxic chloramine gas. Make chloramine by adding dilute hypochlorite slowly into dilute ammonium chloride while it stirs, with a teacher present.
  • Read the SDS for every chemical, especially acetonitrile. The fair has extra rules for some chemicals.
  • Cipro waste goes in a labeled bottle. Bleach the bacteria cultures before disposal.
